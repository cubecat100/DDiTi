# Hi, DDiTi

### 📌 프로젝트 목적

본 프로젝트는 대학교 학사 관리 업무의 효율성과 접근성 향상을 목표로 합니다.

- 학사 프로세스 자동화로 업무 효율성 증대
- 학사 정보의 정확성과 안정성 보장
- 처리 속도 향상을 통해 학생·교수·교직원 모두에게 편리한 서비스 제공

### 🛠️ 사용 API 및 라이브러리

- 메일 API
- 주소 API
- 엑셀 처리 (Apache POI)
- 캘린더 API
- 지도 API
- jsPDF, Canvas
- WebSocket API
- reCAPTCHA API
- SweetAlert API
- GridStack
- 워크넷 API
- 음성인식 Web Speech API

### ✨ 주요 기능

👨‍🎓 학생

- 실시간 수강 신청
- 커뮤니티 기능
- 공유 시간표
- 커뮤니티 채팅
- 실시간 채팅 / 화상 채팅
- 온라인 시험 응시 & 자동 채점
- 증명서 발급 및 결제

👩‍🏫 교수

- 강의 관리 (과제, 시험, 출석, 점수 등록 등)
- 온라인 성적 관리

🏢 교직원

- 학생/교수 정보 일괄 등록 및 관리
- 설문 조사 결과 조회 (차트 시각화)

🌐 공통

- 로그인 및 개인정보 관리
- 음성인식 기반 비서 챗봇
