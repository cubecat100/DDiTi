# Hi, DDiTi

[데모 페이지](https://cubecat.duckdns.org/)

### 📌 프로젝트 목적

본 프로젝트는 대학교 학사 관리 업무의 효율성과 접근성 향상을 목표로 합니다.

- 학사 프로세스 자동화로 업무 효율성 증대
- 학사 정보의 정확성과 안정성 보장
- 처리 속도 향상을 통해 학생·교수·교직원 모두에게 편리한 서비스 제공

### 나의 역할 (PL, 프로젝트 리더)

전체 일정 및 인력 관리, 회의 주도, 산출물 검수
요구사항 분석 및 문서화 총괄 (요구사항 정의서, 유스케이스 정의 등)
각 산출물(정의서, 다이어그램, 설계 문서 등) 방향 설정 및 표준화 주도

사용 API/라이브러리의 도입을 위한 가이드 문서 작성
DB 설계에 대한 전반적인 보조
WebSocket을 이용한 채팅 및 실시간 기능 구현

### 🛠️ 사용 API 및 라이브러리

- 메일 API
- 주소 API
